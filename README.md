# 生物連連看

可安裝的網頁遊戲，支援 Windows、Android 與 iPhone/iPad 瀏覽器。遊戲紀錄只儲存在玩家自己的裝置。

## 線上遊玩與安裝

將此專案部署到 HTTPS 靜態網站後，以瀏覽器開啟網址，選擇「安裝到裝置」即可加入桌面或主畫面。iPhone/iPad 請使用 Safari 的「分享」→「加入主畫面」。遊戲盤面建議橫向操作。首次載入後，Service Worker 會快取遊戲與牌面圖片，之後可離線遊玩。

## 本機預覽

在專案資料夾執行 `python -m http.server 8765`，再開啟 `http://localhost:8765`。PWA 安裝功能需要 HTTPS 網站；localhost 僅供本機開發使用。

## 遊戲內容

- 固定 18 欄 × 12 列、108 對牌，共 13 關。
- 連線最多轉兩次彎，不可穿過其他牌，並可繞過盤面外框。
- 每關提示與洗牌初始各 5 次，配對有機率取得時間、洗牌或提示獎勵。
- 配對、剩餘時間、最高分與前十名排行榜均在本機保存。
- 34 張原創生物牌面圖片位於 `assets/creatures/`。
